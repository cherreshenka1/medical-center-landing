# Медицинский центр «Здоровье»

**Многостраничный адаптивный лендинг**

Коммерческий проект, выполненный в веб-студии **D-project** 

### О проекте
Современный многостраничный сайт медицинского центра с чистым, спокойным дизайном.  
Разработан по макетам Figma с акцентом на удобство пользователя, доверие и конверсию.

### Что было реализовано
- Полноценная многостраничная структура (Главная, Услуги, О нас, Врачи, Отзывы)
- Адаптивная и кросс-браузерная вёрстка
- Красивые карточки услуг с ценами
- Страница врачей с фото-заглушками
- Блок отзывов пациентов
- Интерактивная форма записи на приём
- Современный медицинский UI/UX

### Технологии
- **HTML5**
- **CSS3** (отдельный файл `styles.css`)
- **JavaScript** (отдельный файл `script.js`)
- Адаптивная вёрстка (Flex + Grid)
- Font Awesome
- Семантическая разметка
